# 2026-11-23 收录漫剧老李 Skill

- 项目：<https://github.com/lixiaoxiao9888-create/manju-laoli-skill>
- 分类：Agent Skills、MCP 与剪辑工具
- 定位：面向 AI 漫剧与短剧的 OpenClaw Skill 套装（1 总控 + 10 子技能），覆盖剧本、资产锁定、分镜、打戏、Seedance 投喂提示词与机检
- 许可：MIT；根目录与 `short-drama-director/` 各有一份 MIT LICENSE

套装以「用户只决定做什么、来源、模型、画幅和结果，规则与路由由总控内部完成」为设计。总控 `short-drama-director` 负责素材来源与形态、锁系统、规则库、七段式提示词和机检；子技能分别承担决策、采风、剧本、资产、文戏分镜、通用/玄幻/写实打戏、投喂和质检。包内不持有图片，只交付提示词与接线说明，素材由用户在 Seedance 等外部平台生成并持有；唯一视频模型线为 Seedance 2.5/2.0，Agent 平台覆盖 OpenClaw、Coze、Dify、WorkBuddy 等。

归入 Skills 而非制作工作台：交付形态是供 Agent 执行的 SKILL.md、规则库与 Python 机检脚本，本身不提供时间线或成片界面。

功能判断固定到默认分支提交 `a01e647ac10134918a5de1b18bfe9317e5541a44` 的官方 README（V7.5.0-SLIM；仓库描述仍写 V7.4.26），未安装或实机测试。仓库根和 `short-drama-director/` 均提供 MIT LICENSE。作者在仓库描述中标注为测试版并「二次修改整合开源内容」，但未提供逐项第三方 NOTICE；规则库文本和示例的再分发条件需自行核验。赞助商链接、模型调用和外部素材费用另计。
