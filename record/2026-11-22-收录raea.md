# 2026-11-22 收录 raea

- 项目：<https://github.com/shinyobjectz/raea>
- 分类：Code-to-video 与动效
- 定位：用 React/TypeScript 编写视频、动效、3D 与游戏，在本地 GPU 渲染，并提供对话式桌面工作台与 Agent Skills
- 许可：FSL-1.1-ALv2（源码可见，限制竞争性产品；各版本发布两年后转 Apache-2.0）

raea 自述为 Render Anything Engine。同一份 React 组件可按帧渲染 MP4、实时播放为游戏、导出单帧供 Agent 检查，或用 `raea check` 检查文字裁切、对比度、安全区、冻结帧和响度。桌面应用把对话、项目反馈、时间线和审阅集中在一起；`skills/` 内的 Agent Skill 会由安装器写入 Claude Code 等技能目录。

归入 Code-to-video 而非编辑器或 Agent 生产：核心是代码编写与本地 GPU 渲染，桌面应用和时间线是围绕该引擎的工作台能力。

功能判断固定到默认分支提交 `0c9fc255f2287f0530fc773b895cb5d1877a6f54` 的官方 README，未安装或实机测试。引擎与桌面应用免费；云存储、跨机搜索和发布属于 Pro/Team。
