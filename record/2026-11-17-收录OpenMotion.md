# 2026-11-17 收录 OpenMotion

- 项目：<https://github.com/nexu-io/openmotion>
- 分类：Agent 视频生产与自动化
- 定位：用本地 coding agent 复刻参考视频并替换品牌、文案和素材，在 Studio 中继续编辑并导出 MP4
- 许可：Apache-2.0；内置模板、模型图标及第三方组件的许可证与 NOTICE 另计

OpenMotion 以 HTML、CSS 和 JavaScript 表达镜头、排版、转场与时间，使用 Motion.md 记录镜头顺序、节奏和品牌上下文。它支持从参考视频或社交视频链接开始，由本地 Agent 拆解和重建镜头，再在可视化时间线中调整并输出 MP4；外部图像、视频、音乐和语音生成采用 BYOK 模式。

功能判断固定到默认分支提交 `fcbaa2b0296167b0f14f47aa6c414f5bdd41316f` 的官方 README，未进行安装、实际复刻或成片质量测试。参考视频复刻不等于获得原视频、人物、音乐、素材、商标或再发布授权，使用者需自行核验。

仓库根 LICENSE 是标准 Apache-2.0。仓库同时包含 HyperFrames 示例、模型图标、模板和 vendor 依赖的独立 LICENSE/NOTICE；复用或分发这些内容时，需要按对应文件保留归属并核对许可。
