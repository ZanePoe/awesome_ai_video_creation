# 2026-11-20 收录 AI 短剧与短视频项目

来源：[用户提供的帖子](https://x.com/shenghouxuyao/status/2123241101624758405)，包含三个项目。功能和许可按各自固定提交的官方文档核验，未安装或实测。

- [Pixelle-Video](https://github.com/ATH-MaaS/Pixelle-Video)：全自动短视频流水线；旧的 AIDC-AI 仓库地址已转至 ATH-MaaS。Apache-2.0，第三方依赖见 NOTICE。
- [Jellyfish](https://github.com/Forget-C/Jellyfish)：剧本、分镜、资产管理和镜头生成的短剧工作台。Apache-2.0。
- [Waoowaoo](https://github.com/waooAI/waoowaoo)：当前 README 描述为带 Assistant 和素材画布的图片与视频工作台，仍处于测试阶段。自 v0.5.0-beta.1 起采用 Elastic License 2.0；第三方托管主要功能需要授权，旧版本可能使用不同许可。

模型调用、音视频素材与第三方依赖的费用和许可需分别核对；帖子描述不作为实际成片表现的证明。
