# 2026-11-25 收录 CutVoke

来源：[用户提供的帖子](https://x.com/jaywcjlove/status/2125372881341382959)（2026-11-24，@jaywcjlove / 小弟调调）。帖子只列一个项目 <https://github.com/frankShan001/CutVoke>，描述为「支持 MCP 的 AI 视频编辑器」，与官方 README 一致。

- 项目：<https://github.com/frankShan001/CutVoke>
- 分类：视频编辑器与制作工作台
- 定位：本地优先的跨平台（Windows/macOS/Linux）开源视频剪辑器，内置 MCP server，Agent 与人在同一条非破坏性多轨时间线上协作
- 许可：MIT（版权 frankShan001）

核心是一条声明式时间线，同时被可视化编辑器、CLI、HTTP API 和 MCP server 读写（`cutvoke-mcp` 启动服务，`profile/mcp-config.json` 已含内置引擎命令，接 Claude Code/Codex/Cursor 无需另装 Python）。能力包括：按删除文字的方式剪切（transcript cutting）、本地 ASR 生成可编辑字幕轨（可选 faster-whisper，模型首次下载后可离线）、多轨混音与背景音乐 ducking、参数化可检视的社区特效配方（`effects/`）、本地人体分割模型（`cutvoke-person-model`）与 OpenGL 3D 平面，导出走本地 FFmpeg。官方定位为可脚本化的开源 CapCut 替代，并说明与黑盒 AI 生成器和纯 FFmpeg MCP 封装的差别。

归入制作工作台而非 Skills：交付主体是带时间线界面的桌面编辑器，MCP/CLI/HTTP 是同一项目的四种入口之一。与 OpenChatCut、Concat 同类。

成熟度风险（官方自述，非本合集实测）：v0.3.6 是冻结预览且与 `main` 不同步，仓库文档跟随 `main`，下载版应看 v0.3.6 源码树；发布说明列出导出窗口复用被禁用、重试不续跑已完成窗口，试听/键盘超时与分屏后关键帧错位未完全解决，Linux 导出中竖屏长字幕出现裁切，macOS 包为 ad-hoc 签名、未做 Developer ID 签名与公证。仓库 2026-09-15 创建，Star 44、forks 5，但 30 天 412 次提交，迭代集中在早期。

许可与数据边界：源码 MIT；桌面包内置 FFmpeg（GPLv3）等自有许可组件；社区特效配方、faster-whisper 模型、以及所连接的 Agent（多为云服务，有各自账号、费用与数据政策）另计。README 强调本地剪辑不出网、无需账号，云端 AI 部分由所选服务计费。
