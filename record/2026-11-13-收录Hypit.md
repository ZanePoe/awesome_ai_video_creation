# 2026-11-13 收录 Hypit

- 项目：<https://github.com/hypit-ai/hypit>
- 分类：Agent 视频生产与自动化
- 定位：将参考视频复刻为可编辑、可重复运行的工作流，并批量生成变体
- 许可：Hypit Open Source License，修改自 Apache-2.0，含额外商业限制

Hypit 为 Claude Code、Codex 等 coding agent 提供视频工作流语言和执行系统。它可以从参考视频重建素材、字幕、B-roll 和特效，也可以从描述或模板开始；生成模型不是必需项，纯代码画面可以本地渲染。

功能判断固定到提交 `6bacce093695ccc2bde5aa5d7de230e9682ffa79` 的 README，未进行实机成片测评。热门视频复刻不等于自动获得原视频、肖像、音乐、素材、商标或再发布授权。

许可证允许组织内部及自用商业工作，但限制多租户托管、向第三方商业再分发，并要求保留 CLI、报告和用户界面中的名称、Logo 与版权信息。相关用途需要商业许可，因此目录标记为 source-available，而不是标准 Apache-2.0。
