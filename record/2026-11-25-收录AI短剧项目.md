## 1. 魔因漫创 Moyin Creator

- 项目：<https://github.com/MemeCalculate/moyin-creator>（TypeScript/Electron，AGPL-3.0 + 商业双重许可）
- 分类：视频编辑器与制作工作台；4,871 Stars、90 天 2 次提交、最近提交 2026-08-27、维护分 44.9
- 定位：Electron 桌面生产工具，五大板块「剧本 → 角色 → 场景 → 导演 → S级（Seedance 2.0）」逐级自动衔接，面向短剧/番剧/预告片的批量化生产
- 机制（据固定提交的官方 README）：剧本解析引擎拆解场景、分镜、对白、情绪与镜头语言；角色一致性用「6 层身份锚点」+ 角色圣经（Character Bible）+ 参考图绑定；场景多视角联合图；分镜带景别/机位/运动参数并可切 2D/3D/写实/定格；S级板块做多镜头合并叙事、@Image/@Video/@Audio 多模态引用、首帧 N×N 网格拼接，并校验 Seedance 2.0 约束（≤9 图 + ≤3 视频 + ≤3 音频、prompt ≤ 5000 字符）；一键全流程 + 并行队列 + 失败重试；多供应商调度与 API Key 轮询；技术栈 Electron 30、React 18、electron-vite、Zustand、Radix + Tailwind，AI 核心为内部包 `@opencut/ai-core`。

许可风险：`LICENSE` 是 AGPL-3.0 正文，README 与 `COMMERCIAL_LICENSE.md` 声明双重许可——闭源修改、集成商业产品或提供 SaaS 而不开源需要购买商业许可。AGPL 的网路传染条款对二次分发和托管都有效用，商用前需读原文。

维护与版本风险（本次核查发现，帖子未提）：仓库只有 `main` 一个分支，`main` 最后一次非文档提交为 2026-08-27，其后的提交集中在 README（新增赞助商区块与图片）；Releases 里最近（2026-11-20）发布的是 `定制版memefast-v0.0.1`，上一个功能版本是 2026-06-17 的 `V0.2.9`；而 README「下载」一节给的是网盘上的 0.1.7 包并声称「对应开源源码」，与 Releases 版本对不上。README 顶部还有 Memefast API 中转站的赞助位。使用前建议直接比对源码提交与所需模型的当前接口。

## 2. 火宝短剧 Huobao Drama

- 项目：<https://github.com/chatfire-AI/huobao-drama>（TypeScript，默认分支 `master`，CC BY-NC-SA-4.0）
- 分类：视频编辑器与制作工作台；17,971 Stars、90 天 108 次提交、最近提交 2026-11-21、维护分 84.4、最新标签 v4.0.11
- 定位：一句话或粘贴小说 → AI 改写为分集拍摄剧本 → 角色/场景出图 → 分镜视频生成 → 配音与字幕 → 合成成片的一站式平台，Web/桌面/Docker 三种形态
- 机制（据固定提交的官方 README）：后端 Hono + Drizzle ORM + Mastra AI Agents + better-sqlite3，`backend/workspace/skills/` 放 Agent 技能定义（SKILL.md）并支持界面在线编辑；前端 Nuxt 3 + Vue 3（纯 CSS）；`desktop/` 为 Electron 版；Docker 镜像 + Watchtower sidecar 提供应用内更新；界面内置中/英/日/韩四语，并可全局设定 AI 生成语言；文本走 OpenAI 兼容接口或 Gemini，图片走 OpenAI/Gemini/火山引擎，视频走 Seedance 2.0（Standard/Fast/Mini）、MiniMax H3、阿里百炼 Wan 3.0；API Key、Base URL 与模型参数全部存数据库而非环境变量。

许可风险（重点，帖子未提）：`LICENSE` 为 CC BY-NC-SA 4.0 全文，README 许可证一节写明**禁止商用**，包括付费服务、商业部署与转售，商业使用需作者事先书面许可；GitHub 因识别不了而显示 NOASSERTION。想用它做变现短剧矩阵前，先确认是否拿到书面授权。

其他边界：所有 AI 能力都要自备模型服务，README 用「火宝快捷配置」引导粘贴 FireMux（api.firemux.cn）密钥一键写入三条推荐配置，也可手动按厂商配置；Seedance 引用本地参考资源需要 `PUBLIC_BASE_URL` 公网地址，桌面版没有公网入口，该场景会直接报错（文生视频与图片等不受影响）；媒体落在 `data/static/` 与 SQLite，官方说明迁移只覆盖数据库行、媒体要手动拷贝；项目自带 donate 二维码与赞助 CTA。

两条分类口径：都归入制作工作台（与 Jellyfish、AID Studio 同类），而非 Agent 生产——交付主体是带界面的生产平台，Agent 编排与批处理是其内部实现。

核查方式：功能与许可判断分别固定到 `MemeCalculate/moyin-creator@7e5c5655de94d49885e13c369f0a71212893a0aa` 与 `chatfire-AI/huobao-drama@24d4c17612e71cf10c8eeb1a8b6439afa73e2c07` 的官方 README、LICENSE、COMMERCIAL_LICENSE.md 与目录树；未安装、未部署、未实机出片，版本与维护结论来自 GitHub API 的分支、提交与 Releases 列表。
