# 2026-11-24 收录 pixelfx

来源：[用户提供的帖子](https://x.com/RoundtableSpace/status/2125065621578670259)（2026-11-24，@RoundtableSpace / 0xMarioNawfal）。帖子只列一个项目，Source 链接为 <https://github.com/patch-gg/pixelfx>（x.com 与 t.co 本机不可直连，链接经 `api.fxtwitter.com` 取回并核对）。

- 项目：<https://github.com/patch-gg/pixelfx>
- 分类：Agent Skills、MCP 与剪辑工具
- 定位：244 个以代码绘制的像素特效与动画库，附 Claude Code 特效生成 Skill 和精灵表、GIF/MP4 导出工具
- 许可：MIT（代码与特效）+ Patch Pixel 字体除外

每个特效是 `src/fx/<类别>/<名称>.js` 一个文件，分 21 类（fire、explosions、water、ice、lightning、sci-fi、melee、impacts、projectiles、spawn & death、arcane、holy、shadow、status、nature、weather、ui、pickups、transitions、critters、moves）。纯特效导出 `draw(p, t, o)`，模拟特效导出 `create(o)` 并以 120 Hz 步进真实粒子，两种都写入 `color` 与 `light` 双缓冲；随机数全部由 seed 决定，第 40 帧每次相同。61 个带角色的特效与 12 个 moves 带 `act` 时间线（预备、命中定格、恢复），角色是 3D 骨架渲染成像素。

用法：浏览器游戏里直接 `import` 代码（无依赖，适配 canvas/Phaser/PixiJS/three.js）；其他引擎用 `node tools/render.mjs <id> --sheet` 或 `node tools/sheets.mjs` 导出透明 PNG 精灵表加 Aseprite 风格 JSON（Phaser atlas、Godot/Unity Aseprite 导入器可读）；`--gif`/`--mp4` 输出动图；`palette` 可整片换色。Claude Code Skill 通过 `/plugin marketplace add patch-gg/pixelfx` 安装，负责查找、使用、导出和按「画—渲染—看—改」循环制作新特效。

归入 Skills 而非 Code-to-video：主交付是特效素材库与配套的 coding agent Skill、确定性导出/自检脚本，不是从脚本到成片的渲染框架。与 HyperFrames Motion Library 同类。

功能判断固定到默认分支提交 `5294518ce7c72e48b6100a744596e0acf57f2826` 的官方 README、NOTICE.md 与 `gallery/fonts/NOTICE.md`，未安装或实机渲染。

许可需分段：README 声明代码与特效为 MIT、可商用；NOTICE.md 记录 `src/core/sim.js` 及部分特效改编自 Hugo Duprez 的 Sprite Fusion 开源特效（MIT）、`src/core/act.js` 改编自 Hollow Crown（rehan-remade，MIT），再分发需保留归属；`gallery/fonts/PatchPixel-Regular.woff2` 为 Patch 保留所有权利，不在 MIT 范围内。帖子中的「244 effects」与仓库计数标记一致，但导出素材中若含第三方游戏画面、角色或音乐，需自行核验。
