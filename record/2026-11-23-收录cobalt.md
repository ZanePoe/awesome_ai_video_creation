# 2026-11-23 收录 cobalt

- 项目：<https://github.com/imputnet/cobalt>
- 分类：下载、采集、转码与素材 CLI
- 定位：无广告、无追踪、无付费墙的媒体下载 Web 应用与可自托管 API，覆盖 YouTube、TikTok、Instagram、Twitter/X、Bilibili 等站点
- 许可：AGPL-3.0（api 与仓库其余部分）+ CC-BY-NC-SA-4.0（web）；品牌与吉祥物单独版权

cobalt 是 monorepo：`api/`（Express 服务与流处理）、`web/`（Svelte 前端）、`packages/` 和 `docs/`。粘贴链接即取文件，不缓存内容，工作方式接近代理。官方没有公开预托管 API，需要使用 API 时按 `docs/run-an-instance.md` 自行部署（推荐 Docker Compose），`docs/protect-an-instance.md` 给出限流与鉴权做法。下载能力按站点分列「视频+音频 / 仅音频 / 仅视频 / 元数据 / 富文件名」，并标注不支持或不适用的组合。

归入下载与素材类而非编辑器：只负责取回素材，不提供时间线、剪辑或导出流程。与 yt-dlp 的差异是交付形态——cobalt 是 Web/API 服务，yt-dlp 是命令行解析器。

功能判断固定到默认分支提交 `a636575b09de1fc55d9b8cd98cac88f5f2f16b42` 的官方 README 与 `api/README.md`、`web/README.md`，未部署实例或实机下载测试。

许可需分段核验：仓库根与 `api/LICENSE` 为 AGPL-3.0；`web/` 代码为 CC-BY-NC-SA-4.0，禁止商用，且要求同许可再发布；品牌和吉祥物不在代码许可内，仅允许非商业托管未修改实例。remux/encode 依赖 imputnet 的 libav.js（FFmpeg 浏览器构建），其组件许可另列。官方公开实例与自建实例的服务条款、站点变更和平台条款是不同风险；下载内容的人物、音乐与再分发授权由使用者自行核验。
