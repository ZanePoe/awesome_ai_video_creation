# 2026-11-27 收录 Editroom

- 项目：<https://github.com/robbietilton/Editroom>
- 分类：视频编辑器与制作工作台
- 定位：macOS 原生 Swift 编辑器，4K 实时不建代理，内置调色、变速曲线、转场、混音与响度目标导出，并可用自然语言让 Claude、ChatGPT 或端侧模型下刀
- 许可：MIT（应用）+ 内置 FFmpeg LGPL-2.1+、Sparkle MIT
- 来源：[用户提供的帖子](https://x.com/wquguru/status/2125978104263065684)（2026-11-26，@wquguru）

Editroom 由设计师 Robbie Tilton 开发。帖子称其参与过 Apple Vision Pro 与 Google Glass 界面设计，但仓库 README 与官网 <https://robbietilton.com/editroom>（HTTP 200，页面内无 Vision Pro / Google Glass 表述）都没有该履历记载，因此不作为功能依据。仓库创建于 2026-11-16，到 2026-11-27 已有 12 个 release（v1.0 至 v1.0.11，其中 v1.0.6–v1.0.10 五个发在 11-26 一天内），90 天 428 次提交。README 声明的能力：4K 从剪辑到导出实时、无代理无缓冲（L7、L20）；打开 iPhone/Canon/Sony/Nikon/Fuji 素材及 macOS 自身打不开的 MXF、MKV、WebM（L21，靠内附 FFmpeg）；按音乐节拍自动落刀、逐轨 solo/mute/电平与波形、跨片段响度均衡（L37–L39）；-14 LUFS 等响度目标导出与一键竖版/方形/人像裁切（L42–L43）；素材内容检索与逐条转写搜索（L46–L47）；Magic 自然语言剪辑可选 Claude、ChatGPT 或 Local（Apple 端侧模型，README 称"nothing sent anywhere"，L50–L55）；Claude 与 ChatGPT 可通过 MCP 直接编辑当前打开的工程、在时间线上有自己的光标，且无需 API key（L59）。

功能与许可判断固定到默认分支提交 `6390ae7f3847d924126b2d4f7a964b9fee4e71a2` 的官方 README 与 `Vendor/ffmpeg/README.md`，未安装、未实测 4K 实时性能与成片质量。

## 帖子口径与仓库不一致处

- 帖子称「仅 23MB」。README L7 写的是 7.5 MB 应用；v1.0.11 的 `Editroom.dmg` 实际 12,238,527 字节（≈11.7 MiB）。三个数字互不相等，条目按仓库与发布资产记录，不采信帖子数值。
- 帖子称「对比 Premiere ~7GB、DaVinci Resolve ~6GB、iMovie ~4GB」为帖子自述的第三方体积，仓库未提供对照，未收录。
- 帖子称「内置了强大的 AI 能力」，仓库口径更具体：Magic 需要 macOS 14+ 的 Apple Silicon，Local 模式还需 macOS 26 的 Apple Intelligence，Claude/ChatGPT 模式需已登录对应客户端订阅（L63–L65）。

## 许可

仓库根 LICENSE 为 MIT。应用内附 FFmpeg 9.1，LGPL-2.1 或更新版本，`Vendor/ffmpeg/README.md` 说明由 `scripts/build-ffmpeg.sh` 从 ffmpeg.org 官方源码构建、未启用 GPL 或非自由部件，以独立进程运行、只用于转封装 macOS 打不开格式，并被复制进 `Contents/MacOS/ffmpeg` 随应用签名；更新组件 Sparkle 为 MIT。因此 `license_review.status = custom`：分发或再打包时需按 LGPL 提供 FFmpeg 源码与 configure 选项。素材、音乐、字体与第三方插件许可另计；MCP 与 Claude/ChatGPT 模式会把工程与素材交给所选提供商处理，数据外发范围需按模式自行核验。
