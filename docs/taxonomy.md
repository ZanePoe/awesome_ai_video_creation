# 范围与分类

收录能够直接参与视频生成、剪辑、素材分析、数字人、代码动效、Agent 自动化、媒体获取或评测的 GitHub 项目。纯商业产品、只有演示页面而无可复核实现、普通图片生成器和与视频无关的通用 Agent 不进入主目录。

| 分类 | 主要职责 |
| --- | --- |
| 视频编辑器与制作工作台 | 提供时间线、画布、节点、项目文件或完整制作界面 |
| Agent 视频生产与自动化 | 从目标/脚本到素材、剪辑、质检和导出的多步执行系统 |
| 知识类短视频、切片与讲解 | 知识视频、数字人讲解、长视频切片和社交短视频 |
| Agent Skills、MCP 与剪辑工具 | 供 coding agent 调用的 Skill、MCP、CLI 与确定性工具 |
| Code-to-video 与动效 | 用 HTML/React/Canvas/Three.js/Python 等代码渲染视频 |
| 动画、3D 与编码基础组件 | 用于视频场景构建的通用动画、矢量、三维渲染与 GIF 编码工具；标为相邻基础设施 |
| ComfyUI 与开源视频生成 | 扩散/DiT 视频模型、ComfyUI 工作流和生成运行时 |
| 数字人、肖像动画与唇同步 | 人像驱动、说话头像、实时数字人和唇同步 |
| 下载、采集、转码与素材 CLI | 合法素材下载、直播流、转码、封装和基础处理 |
| 评测、研究与外部索引 | 视频生成/编辑 benchmark、研究代码与覆盖索引 |
| 历史与受限版本 | 历史开源版本或当前许可不再开放的项目 |

每个仓库只有一个主分类。一个 Skill 可以调用 Remotion、FFmpeg 或模型 API，但不会因此同时复制到三个分类。

## 重要边界

- Downvid/VidBee 是产品层；yt-dlp、FFmpeg 等是其底层工具。
- Skill/MCP 不等于独立编辑器，必须说明宿主、渲染器和外部服务。
- “本地项目文件”不代表模型 API、ASR、TTS 或素材搜索不出网。
- 代码生成视频、扩散视频和真实素材剪辑是不同生产方式。
- 模型代码许可、权重许可、训练数据、输出政策和人物肖像权必须分别核验。
- 下载工具只适用于用户有权保存和处理的内容，并需遵守平台条款。
- benchmark 结果只有在相同模型、输入、预算和评分协议下才可比较。
