# दायरा और श्रेणियाँ

यहाँ वे GitHub प्रोजेक्ट शामिल हैं जो सीधे वीडियो जनरेशन, संपादन, सामग्री विश्लेषण, डिजिटल प्रस्तोता, कोड मोशन, Agent ऑटोमेशन, मीडिया प्राप्ति या मूल्यांकन में भाग ले सकते हैं। केवल वाणिज्यिक उत्पाद, बिना जाँच-योग्य इम्प्लीमेंटेशन सिर्फ़ डेमो पेज वाले प्रोजेक्ट, साधारण इमेज जनरेटर और वीडियो से असंबंधित सामान्य Agent मुख्य डायरेक्टरी में नहीं आते।

| श्रेणी | मुख्य भूमिका |
| --- | --- |
| वीडियो संपादक और प्रोडक्शन वर्कबेंच | टाइमलाइन, कैनवास, नोड, प्रोजेक्ट फ़ाइल या पूरा प्रोडक्शन इंटरफ़ेस देते हैं |
| Agent वीडियो प्रोडक्शन और ऑटोमेशन | लक्ष्य/स्क्रिप्ट से सामग्री, कट, क्वालिटी जाँच और एक्सपोर्ट तक के मल्टी-स्टेप निष्पादन सिस्टम |
| ज्ञान-आधारित शॉर्ट वीडियो, क्लिप और एक्सप्लेनर | ज्ञान वीडियो, डिजिटल प्रस्तोता व्याख्या, लंबे वीडियो की क्लिप और सोशल शॉर्ट्स |
| Agent Skills, MCP और संपादन उपकरण | coding agent द्वारा बुलाई जाने वाली Skill, MCP, CLI और डिटर्मिनिस्टिक टूल |
| Code-to-video और मोशन | HTML/React/Canvas/Three.js/Python जैसे कोड से वीडियो रेंडर करना |
| एनिमेशन, 3D और एन्कोडिंग बुनियादी घटक | वीडियो सीन बनाने के लिए सामान्य एनिमेशन, वेक्टर, थ्री-डी रेंडरिंग और GIF एन्कोडिंग टूल; इन्हें संलग्न इन्फ़्रासंरचना माना गया है |
| ComfyUI और ओपन-सोर्स वीडियो जनरेशन | डिफ़्यूजन/DiT वीडियो मॉडल, ComfyUI वर्कफ़्लो और जनरेशन रनटाइम |
| डिजिटल प्रस्तोता, पोर्ट्रेट एनिमेशन और लिप-सिंक | चेहरा-संचालित एनिमेशन, बोलता अवतार, रियल-टाइम डिजिटल प्रस्तोता और लिप-सिंक |
| डाउनलोड, संग्रह, ट्रांसकोडिंग और सामग्री CLI | कानूनी सामग्री डाउनलोड, लाइव स्ट्रीम, ट्रांसकोडिंग, मक्स और बुनियादी प्रोसेसिंग |
| बेंचमार्क, शोध और बाहरी इंडेक्स | वीडियो जनरेशन/एडिटिंग benchmark, रिसर्च कोड और कवरेज इंडेक्स |
| ऐतिहासिक और प्रतिबंधित संस्करण | ऐतिहासिक ओपन-सोर्स संस्करण या जिनका वर्तमान लाइसेंस अब खुला नहीं है |

हर रिपॉज़िटरी की केवल एक मुख्य श्रेणी होती है। एक Skill Remotion, FFmpeg या मॉडल API को बुला सकती है, पर इससे उसे तीनों श्रेणियों में एक साथ नहीं दोहराया जाता।

## महत्वपूर्ण सीमाएँ

- Downvid/VidBee उत्पाद-स्तर हैं; yt-dlp, FFmpeg आदि उनके नीचे के उपकरण हैं।
- Skill/MCP का मतलब स्वतंत्र संपादक नहीं है; होस्ट, रेंडरर और बाहरी सेवा स्पष्ट करनी होती है।
- “लोकल प्रोजेक्ट फ़ाइल” का मतलब यह नहीं कि मॉडल API, ASR, TTS या सामग्री खोज नेटवर्क से बाहर नहीं जाती।
- कोड से वीडियो, डिफ़्यूजन वीडियो और असली फ़ुटेज का संपादन — ये अलग-अलग उत्पादन तरीके हैं।
- मॉडल कोड का लाइसेंस, वेट का लाइसेंस, ट्रेनिंग डेटा, आउटपुट पॉलिसी और व्यक्ति के चेहरे के अधिकार — हर एक अलग जाँचा जाता है।
- डाउनलोड टूल का उपयोग केवल उसी सामग्री के लिए जो उपयोगकर्ता सहेजने और प्रोसेस करने का अधिकार रखता है, और प्लेटफ़ॉर्म के नियमों का पालन करना ज़रूरी है।
- benchmark के नतीजे केवल तभी तुलना-योग्य हैं जब मॉडल, इनपुट, बजट और स्कोरिंग प्रोटोकॉल एक जैसे हों।
